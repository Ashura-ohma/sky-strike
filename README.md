# 逐风 · 英雄战境 V6

横屏 3D 单机 MOBA，Android 离线安装包，版本 0.6.0。

## V6：自动锁定、德莱文与高清画面

- **点按自动瞄准**：松手施法时重新选择技能实际范围内可见的敌人，优先手动锁定英雄与普攻目标；敌方英雄优先于小兵。范围技能落在目标位置，弹道适量提前瞄准移动目标。
- **拖动手动瞄准**：明确拖动后保持手动方向，移回按钮附近也不会突然切回自动；位移、治疗与自身强化按技能类型处理。点击战场中的敌方英雄可锁定，再次点击或点击目标条的取消按钮解除。
- **德莱文**：旋转飞斧强化普攻，地面金色落点提示接斧，接住后恢复飞斧并刷新血性冲刺；开道利斧推开并减速敌人；冷血追命往返造成物理伤害，可再次点击提前折返。崇拜随接斧、补兵积累，击败英雄兑现额外金币，阵亡损失一半层数。
- **德莱文模型与界面**：双弯斧、非对称铜甲、上梳发型与胡须；头像、四个技能图标、双斧与崇拜状态、接斧反馈、再次施放大招提示。新增英雄的战绩和熟练度可正常保存。
- **清晰度**：首次升级至 V6 默认高清，保留已选流畅模式；高清最多 2 倍设备像素比例且限制总像素预算。自动画质不再降至 0.85 倍，血条覆盖层适配高分屏，地表绘制纹理提高至 4096×4096，增强斜视贴图过滤。
- **场景打磨**：草丛融入地面，去除平涂圆片，补充河岸碎石与草地细节；新增旋转飞斧、落点倒计时、接斧闪光与加速轨迹。

德莱文为本项目制作的单机适配版本，技能数值、射程和节奏适配本地图；图像为新生成的角色插画，战斗模型与效果由项目代码制作。[技能参考：英雄联盟角色介绍](https://www.leagueoflegends.com/en-us/champions/draven/)。

## V5：画风与移动重制

- **重做战场材质**：原创手绘草地、石路、苔岩和水面图集，过渡河岸、阔叶树冠、符文防御塔与水晶基地。
- **六英雄模型与动作**：成人头身比例、曲面渐变盔甲、职业武器与服装；膝肘关节跑步、平滑转身及独立攻击动作。
- **战斗界面**：深蓝与细金边界面、24 个手绘技能图标、半透明战斗按钮、英雄头像裁切。
- **模拟摇杆**：浮动中心、圆形死区和按推杆幅度变速；松手立即停止，镜头旋转后的屏幕方向与触控保持对应，多点触控可同时移动、普攻和瞄准。
- **运动与碰撞**：60 Hz 固定步长模拟、渲染插值、时间无关加速；岩石滑行碰撞、位移防穿墙，点选移动与电脑英雄绕障碍。修复普攻追击与点选目的地叠加导致一帧移动两次的问题。
- **渲染优化**：合并静态场景、小兵网格和弹道；实例化接触阴影、资源缓存与释放，提供自动、流畅、高清画质和可选帧率显示。
- **沿用 V4 安装配置**：保持 V4 应用 ID 与缓存签名路径；构建后应比对 V4/V5 签名一致，再覆盖升级保留应用数据。V2/V3 仍为独立应用。

玩法仍保留以下 V4 与原有内容。本次重点是实际战斗画面与移动手感，素材均打包在本地。

## V4：迷雾与征途

- **六章峡谷征途**：补兵、装备、圣坛、猎龙、英雄击败和双目标决胜。逐章解锁，有明确的必达目标、三颗星和首次通关星币；重玩保留最佳星级，不重复发首次奖励。
- **战争迷雾与草丛**：队伍共享英雄、小兵、建筑和守卫视野；看不见的敌人不能被自动选中。草丛内的敌人需要靠近、入草或放置守卫发现。
- **侦察守卫**：在脚下插眼，视野半径 18、持续 45 秒，冷却 35 秒。
- **三种召唤技能**：闪现位移、屏障保命、惩戒野怪，出战前选择；有独立冷却。
- **河道圣坛**：35 秒出现，在光圈内无敌人干扰站满 5 秒可占领。全队获得 120 金币、额外恢复和河道视野 75 秒；双方在圈内时暂停占领。
- **战场契约**：补兵、摧塔和野区目标各有一次性金币奖励。
- **操作优化**：小地图点选移动、职业推荐装备与快捷购买、镜头距离调节、音效与画质设置保存、战境手册。
- **场景丰富**：实体草丛、迷雾、守卫、圣坛与所有权标识、移动落点、攻击范围、战斗反馈。
- **独立安装**：V4 与 V3 使用不同应用 ID，可同时保留。V3 的云端调试签名未成功缓存，不能覆盖升级；V4 使用新的独立存档，不会迁移 V3 战绩。

## 原有玩法

- **7 名英雄、28 个主动技能**：剑士、法师、射手、坦克、刺客、治疗辅助与飞斧射手，每名英雄有独立被动。
- **5v5 三路战场**：电脑英雄使用多种技能、撤退和购买装备；小兵每三波加入攻城单位。
- **野区目标**：四处红蓝守卫、65 秒首次苏醒的远古龙王、范围攻击预警。击败龙王后强化全队及新出兵线 70 秒。
- **18 件装备**：物理、法术、防御、移动分类；补差价进阶与七折出售；吸血、暴击、反伤、减速、穿透和冷却属性。
- **成长决策**：每局选择四种符文之一；升级获得技能点；普通技能最多 5 级、终极技能最多 3 级。
- **四档对局设置**：休闲、标准、挑战、自由练习。练习局开局 15 级与 12000 金币，不获得局外奖励。
- **本地档案**：对局星币、旅者经验、英雄熟练度、最近 12 场战绩、三个累计成就、四种模型配色。存于应用本地，卸载或清除应用数据会删除。
- **完整交互**：摇杆移动、按住普攻追击、拖动技能瞄准与取消、技能加点、回城、回血、复活、暂停、实时战况及中路/回防/龙王队伍指令。
- **美术与音频**：离线英雄肖像图集、图鉴、不同职业三维武器、远古龙模型、河道桥梁、野区标记、48 秒循环原创合成背景音乐与技能音效。

游戏采用原创程序化三维战斗模型和生成的手绘风格材质。图鉴肖像是独立生成的概念插画，不是战斗画面。仍为开发版，尚无联网、云存档或商业级动画制作。

## 安装与试玩

Android 8.0+，Android System WebView 需支持 WebGL。应用名 **逐风战境 V6**，包名 `com.indie.moba.zhufeng.v4`，沿用 V4/V5 包名以便覆盖升级，与 V2、V3 分开安装。

建议从 **峡谷征途 → 初临峡谷** 开始：在没有迷雾的第一章熟悉兵线。要直接体验所有技能和装备，可以选择 **自由练习**（15 级、12000 金币，无战绩奖励）。

GitHub Actions 运行战斗、成长、战术与征途测试后生成 `zhufeng-moba-debug-apk`。产物是调试签名 APK；V4 工作流显式生成并缓存 `.signing/debug.keystore`，Gradle 使用同一路径；后续构建在缓存存在时沿用签名。此密钥不上传到源码仓库。真实手机兼容性与帧率仍需实机验证。

## 验证

- 引擎：基地保护、技能消耗和等级、七英雄技能、控制与治疗、装备交易、进阶与出售、防御塔目标、复活、回城、兵线、龙王、难度、符文。
- 自动瞄准：可见性与距离过滤、手动锁定优先、拖动覆盖自动、范围技能落点、功能技能方向和弹道提前量。
- 德莱文：双斧上限、强化伤害、落点接取与刷新、过期丢斧、E 推开、R 往返与再次释放、物理伤害、崇拜兑现、死亡清理。
- 成长：奖励去重、练习模式无奖励、配色消费、存档读取与损坏回退。
- 移动：30/60/120 Hz 行进距离一致、轻推慢走、松手零滑移、斜向限速、岩石绕行与滑行、位移不穿墙、无重复追击移动。
- 输入：摇杆死区、浮动中心、屏幕方向变换、固定模拟时钟与暂停时间重置。
- 浏览器对比：同一 10 英雄 + 30 小兵场景、844×390 与 DPR 1，主要绘制调用从 V4 的 608 次降至 V5 的 183–185 次；渲染提交 CPU 中位数 4.7→2.1 ms。此为软件 Chromium 检查，不代表安卓实机帧率。
- 资源释放：76 个可见模型与守卫、弹道、陨石特效连续重开 4 次，几何体、纹理、着色程序计数保持稳定。
- 移动浏览器：三点同时触控、技能取消、暂停、图鉴、符文、技能加点、商店、指令、首领显示、战况、胜利结算、战绩存储与刷新恢复、配色和练习模式。

```sh
npm test
npm run serve
```

浏览器打开 `http://localhost:8080`。电脑操作：方向键移动，空格普攻，Q/W/E/R 技能，B 回城，F 恢复，T 放置守卫，G 召唤技能，Esc 暂停。也可点击地面移动。

## Android 构建

需要 JDK 17、Gradle 8.9、Android SDK 35。

```sh
python3 scripts/prepare_assets.py
cd android
gradle --no-daemon assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`。无 INTERNET 权限，所有资源在安装包内。

## 源码

- `assets/engine.mjs`：战斗模拟。
- `assets/content.mjs`：新增英雄、装备、符文、难度与成就。
- `assets/profile.mjs`：本地成长、存档与外观解锁。
- `assets/tactics.mjs`：视野、草丛、守卫、召唤技能、圣坛和契约。
- `assets/campaign.mjs`：六章场景规则、解锁、星级、首次奖励与存档。
- `assets/renderer.mjs`：地图、镜头、插值、画质与特效。
- `assets/hero-models.mjs`：七英雄三维模型、骨架动作与资源管理。
- `assets/targeting.mjs`：按技能定义的选敌、锁定、提前瞄准与落点计算。
- `assets/draven.mjs`：德莱文飞斧、接斧、加速、物理弹道与崇拜机制。
- `assets/terrain.mjs`：地图材质、地形过渡与生成纹理。
- `assets/movement.mjs`：模拟运动、连续碰撞与绕障碍寻路。
- `assets/controls.mjs`：浮动摇杆输入和固定步长时钟。
- `assets/game.mjs`：触控、界面、音频与生命周期。
- `assets/art/heroes-atlas.png`：由内置 image_gen 生成的六英雄肖像；完整提示词与制作说明在同目录 `README.txt`。
- `assets/art/terrain-atlas-v5.png`、`assets/art/skill-atlas-v5.png`：原创生成的地形与技能图集；完整提示词与制作说明在同目录 `README.txt`。
- `assets/art/draven-portrait-v6.png`、`assets/art/draven-skills-v6.png`：本项目新生成的德莱文头像与 2×2 技能图集；完整提示词与制作说明在同目录 `README.txt`。
- `assets/audio/theme.ogg`：原创合成配乐；可用 `scripts/generate_music.py` 重新生成（需要 NumPy、FFmpeg）。

这里的 `assets/` 指 `android/app/src/main/assets/`。

Three.js 使用 MIT 许可证，Noto Sans SC 中文字体子集使用 SIL OFL；许可证在 `assets/vendor/`。

修改中文界面后，可用完整的本地 Noto 中文字体重建子集：`python3 scripts/update_font.py /path/to/NotoSansCJKsc-Regular.otf`。该脚本只在本地运行，需要 fontTools，不会上传游戏文字。

在 `Ashura-ohma/sky-strike` 的 `offline-moba` 分支独立维护。

为保证资源上传可靠，大型图集在仓库中以 `asset-parts/` 的二进制分片保存；`asset-parts/manifest.json` 记录顺序和摘要，`scripts/prepare_assets.py` 校验 SHA-256 后无损还原。构建和 `npm run serve` 会自动执行还原。

征途必达目标需要在胜利时满足才算通关；通关得一星，阵亡不超过两次和时限内获胜各加一星。圣坛需本人在圈内完成占领，猎龙需完成最后一击或在附近参与。
